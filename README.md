# Ｓｔｙｌｉｓｔ成績ノート

スタイリストの月次・年間成績を記録するPWA(Progressive Web App)です。ビルド不要・純粋なHTML/CSS/JavaScriptのみで動作します。

## ファイル構成

```
index.html               アプリ本体
manifest.json             PWAマニフェスト
serviceworker.js          オフラインキャッシュ用Service Worker
icon-48.png                └ アプリアイコン(any) 48x48
icon-72.png                └ アプリアイコン(any) 72x72
icon-96.png                └ アプリアイコン(any) 96x96
icon-144.png                └ アプリアイコン(any) 144x144
icon-192.png                └ アプリアイコン(any) 192x192
icon-512.png                └ アプリアイコン(any) 512x512
icon-maskable-192.png       └ アプリアイコン(maskable) 192x192
icon-maskable-512.png       └ アプリアイコン(maskable) 512x512
```

すべて同じフォルダ(リポジトリのルート、またはGitHub Pagesの公開フォルダ)にそのまま置いてください。相対パス(`./`)で参照し合っているため、リポジトリ直下でもサブフォルダ配信(例: `https://<user>.github.io/<repo>/`)でもそのまま動作します。

## GitHub Pagesでの公開手順

1. GitHubで新しいリポジトリを作成する(または既存リポジトリを使う)。
2. このフォルダの中身(上記11ファイル)をリポジトリのルートに追加してコミット・プッシュする。
3. リポジトリの **Settings → Pages** を開く。
4. **Source** を「Deploy from a branch」にし、Branch を `main`(または該当ブランチ)・フォルダを `/ (root)` に設定して保存する。
5. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でアプリにアクセスできる。
6. スマートフォン/タブレットでそのURLを開き、ブラウザの「ホーム画面に追加」からインストールするとPWAとして使えます。

## 今回のチェックで修正した点

- `index.html` がService Workerを `./service-worker.js` という(存在しない)ファイル名で登録しようとしていたバグを修正し、実際のファイル名 `./serviceworker.js` に合わせました。これが直っていないと、オフラインキャッシュが一切効かない状態でした。
- 設定内の「読込・書出」画面(シート)から「バックアップを読み込む」を実行した際、復元後もシートが開いたままで結果(月次入力画面)が隠れてしまう不具合を修正し、復元完了と同時にシートが閉じて結果が見えるようにしました。
- アイコン刷新・キャッシュ対象の変更に合わせて、Service Workerのキャッシュバージョンを更新し、古いキャッシュが残らないようにしました。
- Service Workerのキャッシュ方式を「キャッシュ優先(まず古い内容を表示しつつ裏で更新)」から「ネットワーク優先(オンライン時は常に最新を取得し、取得できない時だけキャッシュを使う)」に変更しました。これにより、Wi-Fiなどネットにつながっている状態でアプリを開けば、初回から最新の内容が表示されます(オフライン時は従来どおりキャッシュから表示され、アプリとしては動作します)。
